📄 PDF to DOC Converter – Java Desktop Application

A simple desktop application built with Java and Swing UI that allows users to convert PDF documents into editable Microsoft Word (DOC) files.

The application provides a user-friendly graphical interface for selecting PDF files and converting them into editable document formats.

✨ Key Features

- PDF Upload: Select PDF files from your computer.
- Document Conversion: Convert PDF documents into editable Word files.
- Desktop GUI: Simple and user-friendly interface built with Java Swing.
- File Management: Choose the output location for converted documents.

🛠️ Technologies Used

- Programming Language: Java
- GUI Framework: Java Swing
- Platform: Desktop Application
